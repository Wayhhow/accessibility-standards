# 无障碍督导标准查询工具

供志愿队员在学校周边进行无障碍督导时实时查阅标准的在线工具。

## 收录标准

| 标准 | 标准号 | 性质 |
|------|--------|------|
| 建筑与市政工程无障碍通用规范 | GB 55019-2021 | 全文强制性 |
| 无障碍设计规范 | GB 50763-2012 | 部分强制 |
| 无障碍设计标准 | SJG 103-2021 | 地方标准（深圳） |

## 功能

- **关键词搜索**：输入关键词即时搜索所有标准条文，支持条文编号、正文、章节名称搜索
- **常见问题速查**：14个常见无障碍问题分类展示，点击展开查看关联标准原文
- **标准大纲**：可展开/折叠的树形结构浏览所有标准条文
- **PDF跳转**：点击"查看PDF"跳转到对应标准PDF的精确页码
